# academic-literature-analysis-team

**文献计量分析团** · v1.0.1 · `team`

> An offline five-agent team that analyzes local reference libraries — bibliometrics, co-occurrence networks, review skeletons — read-only.


Part of the [WorkBuddy Experts](https://github.com/Lucewalk/WorkBuddy-Experts) collection — expert teams, agents and skills for the WorkBuddy AI assistant platform.
